# Profile Strategy: Current State vs. Time-Series & Snapshots

`profile/` 데이터를 전부 날짜별 파일(`YYYY-MM-DD.md`)로 분리하면 시점 보존에는 유리하지만, '현재 나의 최신 상태'를 한눈에 파악하기 어렵고 '일자별 수치 추이(Trend)'를 비교할 때 여러 파일을 열어야 하는 파편화 문제가 발생한다.

따라서 `profile/`은 데이터의 성격에 따라 **현재 상태(고정 파일)**, **수치 추이(단일 표 누적)**, **상세 시점 기록(날짜별 스냅샷 파일)**의 3계층 하이브리드 구조로 관리한다.

- **현재 상태 및 루틴 (`overview.md`, `protocols.md`)**: 항상 최신 상태를 유지하는 단일 파일로 관리하되, 파일 하단의 `Changelog` 섹션에 변경 이력을 한 줄씩 남긴다.
- **일자별 수치 추이 (`measurements.md`)**: 체중, 골격근량, 체지방률 등 자주 측정하며 추이 비교가 핵심인 지표는 단일 파일 내 마크다운 표(Table)에 행(Row)을 누적한다.
- **시점별 상세 스냅샷 (`snapshots/YYYY-MM-DD-<type>.md`)**: 건강검진, 상세 혈액검사, 프로젝트 전후 정밀 측정처럼 내용이 방대하거나 불변의 시점 보존이 필요한 경우에만 날짜가 포함된 파일로 생성하고 `measurements.md`나 `project`에서 링크한다.

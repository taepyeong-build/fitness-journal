# Phase 1 대시보드 사용 안내

[`dashboard.html`](./dashboard.html)을 브라우저에서 열면 된다. 외부 라이브러리·폰트·서버 없이 동작하며, Phase 1의 28일 계획과 모듈 설명을 내장한다.

1. 일자를 선택하고 아침 지표를 입력한다. 숫자·시각 입력은 입력을 마치고 다른 곳으로 이동할 때 반영한다. 필요한 지표가 빠졌으면 자동 판정을 기다리며, 수동 신호등 선택도 가능하다.
2. 당일 `Session Module`, `Meal Module`, `Recovery Module`을 확인하고 수행 완료·식사 마감·취침 시각을 기록한다. 서플리먼트 체크와 직접 확인 항목의 초기 상태는 미확인이다. 영양 예외는 체크를 해제하고, 수면 준수는 필요하면 직접 판정한다.
3. 파일 연결을 지원하는 데스크톱 브라우저에서는 **log.md 파일 연결**로 이 폴더의 [`log.md`](./log.md)를 선택한다. 이후 입력을 순서대로 자동 저장한다. 새로고침 후에는 브라우저 백업을 복원하며, 실제 파일에 계속 저장하려면 다시 연결한다.
4. 파일 연결을 지원하지 않는 환경에서는 파일 불러오기 후 **전체 log.md 복사** 또는 **log.md 다운로드**로 보관한다. 자동 복사가 거부되면 직접 선택해 복사할 수 있는 창이 열린다. 브라우저 백업 실패와 파일 저장 실패는 상단에 표시된다.

기록이 다른 파일로 교체되기 전에는 확인을 요청한다. 외부 편집기에서 파일이 바뀐 것이 감지되면 자동 저장을 멈춘다. 브라우저 쪽 기록을 먼저 다운로드하고, 외부 변경을 확인한 뒤 파일을 다시 연결한다. **초기화**는 확인 후 파일 연결을 해제하고 브라우저 기록을 복원한다.

원문 링크·공백·줄바꿈·추가 메모를 유지하면서 수정한 슬롯과 영향을 받는 주간 요약만 갱신한다. 7열에 없는 서플리먼트 체크, RHR/HRV 편차, SpO2, 수동 판정과 `Progression Gate` 확인은 `log.md`의 `phase1-dashboard:v1` HTML 주석에 함께 보관한다. 이 주석을 유지해야 다른 브라우저에서도 부가 기록이 복원된다. 기존 파일에 미리 적힌 미래 시각은 수행 기록으로 집계하지 않으므로, 실제 수행 후 시각을 입력하거나 빠른 입력 버튼을 누른다.

마크다운에서 직접 바꾼 영양 예외 표시·시각·신호등은 이전 부가 기록보다 우선한다. 이전 버전 브라우저 백업의 측정값·메모·변경한 시각은 복원하며, 실제 입력 여부를 구분할 수 없는 예정 시각과 자동 체크·기본 측정값은 다시 확인한다.

주간 체중 평균에는 입력한 날짜 수를 표시한다. `Progression Gate`는 선택일과 오늘 중 이른 날까지의 기록을 사용하며, 영양·수면은 최근 14일로 집계한다. 대체 운동은 주간 실행에 포함하지만 정규 상한 볼륨의 증거로 쓰지 않는다. 자동으로 알 수 없는 볼륨·RIR·통증 경과·컷오프는 직접 확인하며, 최종 승급은 [`README.md`의 종료 체크리스트](./README.md#4-종료-심사-및-회고-progression-gate--close-out)에서 판정한다. 주간 카드의 **measurements.md 행 복사**는 누적표에 붙일 11열 행을 만든다.

## 검증

저장소 루트에서 Node.js 기본 테스트 러너로 회귀 검증을 실행한다.

```sh
node --test project/2026-10-phase1-onboarding/tests/dashboard.test.cjs
```

실제 브라우저 검증은 Playwright와 Chrome이 있는 환경에서 실행한다. Playwright가 별도 경로에 설치되어 있으면 두 번째 명령처럼 모듈 경로를 전달한다. macOS의 기본 Chrome 경로 이외에는 `CHROME_BIN`을 지정한다.

```sh
node project/2026-10-phase1-onboarding/tests/dashboard.browser.cjs
node project/2026-10-phase1-onboarding/tests/dashboard.browser.cjs /path/to/node_modules/playwright
```

브라우저 검증은 임시 서버를 스스로 열고 종료한다. 실제 FileSystemFileHandle 저장은 브라우저의 임시 저장 공간에서 검증하며, 저장소의 `log.md`는 수정하지 않는다. 데스크톱·390px 모바일 화면 캡처는 운영체제의 임시 폴더에 저장한다. 파일 선택기 자체의 OS 대화상자와 실제 디스크 파일의 권한 요청은 사용 환경에서 확인해야 한다.
